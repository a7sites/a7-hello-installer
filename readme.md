# 📊 A7 Painel de Hospedagem

O **A7 Painel de Hospedagem** é um plugin para WordPress que adiciona um **painel administrativo personalizado** no Dashboard do WordPress com informações essenciais sobre o plano de hospedagem contratado com a **A7 Sites**.

Além disso, o plugin também pode **adicionar funcionalidades e recursos ao tema ativo**, integrando utilidades da hospedagem diretamente no site.

---

## ✨ Características

- 🗓️ Exibe a **data de vencimento da hospedagem** e domínio  
- 🌐 Mostra os **dados DNS da hospedagem** (com e sem Cloudflare)  
- 📦 Informa o **plano contratado** (espaço em disco, memória, contas de e-mail, bancos de dados, SSL, etc)  
- 📇 Cards organizados com os **recursos e limites** oferecidos pela A7 Sites  
- 🎨 Integra funções diretamente ao tema ativo do WordPress  
- 🧭 Layout visual moderno, leve e responsivo  
- 🔒 Somente administradores e editores podem visualizar as informações  

---

## 📥 Instalação

1. Envie os arquivos para o diretório `/wp-content/plugins/a7-painel-hospedagem/`  
2. Ative o plugin em **Plugins > Plugins Instalados**  
3. O painel será exibido automaticamente no Dashboard principal do WordPress  
4. As informações são **preenchidas manualmente pelo programador/desenvolvedor** do site

---

## 🧰 Requisitos

- WordPress 5.0 ou superior  
- PHP 7.4 ou superior  
- Tema com suporte a widgets ou integração de funções personalizadas  

---

## 🔐 Segurança

Todas as informações exibidas são estáticas ou fornecidas manualmente pelo desenvolvedor. Nenhuma informação sensível é enviada a servidores externos.
